Node.js 및 Python 설치

Node.js Version Manager (nvm)

풀스택 개발은 프로젝트마다 서로 다른 Node.js 버전을 요구할 수 있습니다. NVM을 통해 손쉽게 관리하세요.

# NVM 설치 스크립트 실행

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 현재 터미널에 nvm 적용

source ~/.bashrc

# 최신 안정화 버전(LTS) 설치

nvm install --lts

Python 및 가상환경(venv)

FastAPI는 독립된 환경에서 실행되는 것이 권장됩니다. 필요한 패키지들을 설치해 봅시다.

sudo apt update

sudo apt install -y python3-pip python3-venv

💡 왜 PIP와 VENV인가요?

PIP는 파이썬 라이브러리를 설치하는 도구이며, VENV는 프로젝트별로 파이썬 환경을 분리하여 '패키지 충돌'을 방지하는 필수 도구입니다.
