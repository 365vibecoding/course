Step 2-1

VS Code와 WSL 연동

WSL Extension 설치

VS Code를 실행하고 왼쪽 사이드바의 Extensions(Ctrl+Shift+X) 메뉴에서 WSL을 검색하여 설치합니다.

터미널에서 VS Code 호출

이제 Ubuntu 터미널을 열고 프로젝트 폴더를 만든 후 VS Code를 호출해 보겠습니다.

# 프로젝트 폴더 생성 및 이동

mkdir my-project && cd my-project

# 현재 위치에서 VS Code 열기

code .

잠시 기다리면 윈도우에서 VS Code가 실행됩니다. 창 왼쪽 하단의 WSL: Ubuntu 표시를 반드시 확인하세요.
