Windows Subsystem for Linux

🖥️ 1단계: 시스템 요구사항 확인

WSL 2를 실행하기 위한 최소 사양입니다:

  • ✅ Windows 10 버전 2004 이상 (빌드 19041 이상) 또는 Windows 11
  • ✅ 64비트 프로세서 (x64 또는 ARM64)
  • ✅ 관리자 권한 계정

💡 확인 방법

Windows 키 + R을 누르고 winver를 입력하여 현재 Windows 버전을 확인할 수 있습니다.

🚀 2단계: WSL 간편 설치

명령어 한 줄로 설치하기

PowerShell 또는 명령 프롬프트를 관리자 권한으로 실행하고 다음을 입력하세요:

wsl --install

이 명령어가 수행하는 작업:

  • WSL 및 가상 머신 플랫폼 기능 활성화
  • 최신 Linux 커널 다운로드 및 설치
  • WSL 2를 기본 버전으로 설정
  • Ubuntu 배포판 다운로드 및 설치

3~4단계: 재부팅 및 계정 설정

  1. 설치가 완료되면 컴퓨터를 재부팅합니다.
  2. 재부팅 후 자동으로 터미널 창이 열리며 Ubuntu 설치가 마무리됩니다.
  3. 사용자 계정 생성:
    • UNIX 사용자 이름 입력 (소문자 권장)
    • 비밀번호 입력 (보안상 화면에 표시되지 않음)

초기 설정 후 패키지 업데이트를 권장합니다:

sudo apt update && sudo apt upgrade -y

⚙️ 고급 설정

특정 배포판 설치

설치 가능한 리눅스 배포판 목록을 확인합니다:

wsl --list --online

원하는 배포판을 지정하여 설치합니다 (예: Debian):

wsl --install -d Debian

WSL 버전 관리

현재 설치된 배포판과 WSL 버전 확인:

wsl --list --verbose

기존 배포판을 WSL 2로 변환:

wsl --set-version Ubuntu 2

새로 설치되는 배포판의 기본 버전을 2로 설정:

wsl --set-default-version 2

🔧 수동 설치 (구버전 Windows)

1. Windows 기능 활성화

PowerShell(관리자)에서 다음 두 명령어를 실행합니다:

dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
주의: 명령어 실행 후 컴퓨터를 재부팅해야 적용됩니다.

2. 커널 업데이트 및 배포판 설치

  • WSL2 Linux 커널 업데이트 패키지를 다운로드하여 설치합니다.
  • Microsoft Store를 열고 원하는 Linux 배포판(Ubuntu 등)을 검색하여 설치합니다.

🎯 유용한 WSL 명령어

설명 명령어
실행 중인 배포판 확인 wsl --list --running
특정 배포판 실행 wsl -d Ubuntu
WSL 전체 종료 wsl --shutdown
배포판 등록 해제(삭제) wsl --unregister Ubuntu
상태 확인 wsl --status

📁 파일 시스템 접근

Windows에서 Linux 파일 보기

파일 탐색기 주소창에 다음을 입력하세요:

\\wsl$

또는 Linux 터미널에서 explorer.exe . 명령어를 입력하면 현재 폴더가 탐색기로 열립니다.

Linux에서 Windows 파일 보기

Windows 드라이브는 /mnt 디렉토리에 마운트됩니다.

cd /mnt/c/Users/사용자명/

C드라이브의 사용자 폴더로 이동하는 예시입니다.

🔍 문제 해결

오류: 0x80370102 (가상화 미지원)

BIOS/UEFI 설정에서 가상화 기술이 활성화되어 있는지 확인해야 합니다.

  • Intel CPU: Intel Virtualization Technology (VT-x)
  • AMD CPU: AMD-V (SVM mode)

WSL이 응답하지 않을 때

WSL 서비스를 완전히 재시작해보세요:

wsl --shutdown

그런 다음 다시 터미널을 엽니다.

VS Code 통합

🐳

Docker Desktop

설정에서 'Use WSL 2 based engine'을 체크하면 완벽한 Linux 네이티브 성능을 누릴 수 있습니다.

리소스 제한 (.wslconfig)

WSL이 메모리를 너무 많이 사용한다면, Windows 사용자 폴더에 .wslconfig 파일을 생성하여 제한할 수 있습니다.

[wsl2] memory=4GB processors=2
