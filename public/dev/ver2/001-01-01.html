1-1. 풀스택 개발자 과정 소개

본 과정은 윈도우 환경에서 리눅스 기반의 강력한 풀스택 개발 생태계를 구축하고 실습하는 전문 교육 과정입니다.

🎯 학습 로드맵

Part 1: 기반 다지기

WSL2, Ubuntu, VS Code 연동 등 리눅스 표준 개발 환경을 구축합니다.

Part 2: Frontend 기초

Vite와 Tailwind CSS를 사용하여 반응형 UI 및 ToDo App을 제작합니다.

Part 3: React 확장

컴포넌트 기반 아키텍처와 상태 관리를 통해 복잡한 앱을 구성합니다.

Part 4: Backend 구축

Python FastAPI를 사용하여 고성능 API 서버를 설계하고 연동합니다.

💡 왜 이 과정을 들어야 하나요?

윈도우 개발자가 겪는 가장 큰 장벽은 '배포 환경과의 괴리'입니다. 우리는 WSL2를 통해 이 문제를 원천적으로 해결합니다. 실무에서 사용하는 도구를 그대로 사용하여 취업과 실무 투입에 최적화된 경험을 제공합니다.
