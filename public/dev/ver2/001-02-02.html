2-2. Node.js 및 Python 설치

풀스택 개발의 심장인 자바스크립트와 파이썬 실행 환경을 구축합니다.

🟢 1단계: Node.js 설치 (NVM 방식)

직접 설치보다는 NVM(Node Version Manager)을 통한 설치를 강력하게 권장합니다.

# NVM 설치 스크립트 실행
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 설정 반영
source ~/.bashrc

# 최신 LTS 버전 설치
nvm install --lts

🐍 2단계: Python 환경 구축

Ubuntu에는 Python이 기본 내장되어 있지만, 개발을 위해 패키지 관리자와 가상 환경 도구가 필요합니다.

sudo apt update
sudo apt install -y python3-pip python3-venv

Why nvm & venv?

  • NVM: 프로젝트마다 다른 Node.js 버전을 요구할 때 즉시 전환 가능합니다.
  • VENV: 프로젝트마다 독립된 라이브러리 가방을 만들어 시스템 오염을 방지합니다.
