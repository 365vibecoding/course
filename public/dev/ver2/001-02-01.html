2-1. VS Code 설치 및 WSL 연동

윈도우의 편리한 UI와 리눅스의 강력한 파일 시스템을 하나로 연결합니다.

📥 1단계: VS Code 설치

공식 홈페이지에서 Windows용 설치 파일을 다운로드하여 설치합니다. 모든 기본 설정을 권장합니다.

Download VS Code

🔌 2단계: WSL 확장 설치

VS Code 실행 후 Extensions(Ctrl+Shift+X) 탭에서 다음을 설치하세요:

Extension Name: WSL (by Microsoft)

이 확장은 VS Code가 리눅스 서브시스템을 원격 서버처럼 다루게 해줍니다.

⌨️ 3단계: 리눅스에서 VS Code 호출하기

Ubuntu 터미널을 열고 다음 명령어를 입력하여 연동을 확인합니다.

# 테스트 폴더 생성 및 이동
mkdir hello-wsl && cd hello-wsl
# 현재 위치에서 VS Code 열기
code .

처음 실행 시 'Installing VS Code Server' 메시지가 나타나며 연동이 진행됩니다.
