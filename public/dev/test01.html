Windows Subsystem for Linux (WSL) 설치 및 설정 가이드

Windows에서 Linux 환경을 구축하는 가장 효율적인 방법인 WSL의 설치부터 설정까지의 과정을 단계별로 알아봅니다.

🖥️ 1단계: 시스템 요구사항 확인

  • Windows 10 버전 2004 이상 (빌드 19041 이상) 또는 Windows 11
  • 64비트 프로세서
  • 관리자 권한 필요

🚀 2단계: WSL 설치 (간편 설치 방법)

PowerShell 또는 명령 프롬프트(CMD)를 관리자 권한으로 실행하고 다음 명령어를 입력하세요: 

wsl --install

이 명령어는 다음 작업을 자동으로 수행합니다:

  • WSL 기능 활성화
  • 가상 머신 플랫폼 활성화
  • Linux 커널 업데이트
  • WSL 2를 기본값으로 설정
  • Ubuntu 배포판 설치

3단계: 시스템 재부팅

설치가 완료되면 반드시 컴퓨터를 재부팅해야 변경 사항이 적용됩니다.

👤 4단계: Linux 사용자 계정 설정

재부팅 후 Ubuntu 터미널이 자동으로 실행됩니다. 잠시 기다리면 다음을 설정하라는 메시지가 나타납니다:

  1. Unix Useranme: 원하는 사용자 이름 입력 (영어 소문자 권장)
  2. Password: 비밀번호 입력 (보안상 입력 시 화면에 표시되지 않음)
  3. Retype Password: 비밀번호 확인

5단계: 배포판 업데이트

설치 직후에는 보안 및 최신 기능을 위해 패키지를 업데이트하는 것이 좋습니다. 

sudo apt update && sudo apt upgrade -y

⚙️ 고급 설정 (선택 사항)

특정 배포판 설치

사용 가능한 Linux 배포판 목록을 확인합니다:

wsl --list --online

원하는 배포판을 지정하여 설치합니다:

wsl --install -d Ubuntu-22.04
# 또는
wsl --install -d Debian

WSL 버전 관리

현재 설치된 버전 확인:

wsl --list --verbose

WSL 1에서 WSL 2로 변환:

wsl --set-version Ubuntu 2

기본 버전을 WSL 2로 설정:

wsl --set-default-version 2

🔧 수동 설치 방법 (이전 버전 Windows)

⚠️ 주의: 간편 설치가 작동하지 않는 경우에만 이 방법을 사용하세요.

1. Windows 기능 활성화 (PowerShell 관리자)

dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

2. Linux 커널 업데이트

Microsoft 공식 사이트에서 업데이트 패키지를 다운로드하여 설치합니다.

3. Microsoft Store에서 설치

Microsoft Store 앱을 열고 "Ubuntu", "Debian" 등을 검색하여 설치 버튼을 클릭합니다.

🎯 유용한 WSL 명령어

wsl --list --running 실행 중인 배포판 확인
wsl -d Ubuntu-22.04 특정 배포판 실행
wsl --shutdown WSL 전체 종료 (재부팅 효과)
wsl --unregister Ubuntu 배포판 및 데이터 삭제 (초기화)
wsl --status 현재 WSL 상태 확인

📁 파일 시스템 접근

Windows ➔ Linux

파일 탐색기 주소창에 입력:

\\wsl$

Linux ➔ Windows

터미널에서 마운트 경로 이동:

cd /mnt/c/Users/사용자이름/

🔍 문제 해결

가상화 오류 발생 시

BIOS/UEFI 설정 진입 후 다음 옵션이 켜져 있는지(Enabled) 확인하세요:

  • Intel: Intel Virtualization Technology (VT-x)
  • AMD: AMD-V (SVM mode)

WSL 완전 재설정

문제가 지속될 경우 데이터를 지우고 다시 설치합니다:

wsl --shutdown
wsl --unregister Ubuntu
wsl --install

💡 추가 팁

  • 1. Windows Terminal: Microsoft Store에서 설치하면 탭 기능과 테마를 사용할 수 있어 편리합니다.
  • 2. VS Code: 'WSL' 확장 프로그램을 설치하면 Windows의 VS Code로 Linux 내부 파일을 직접 수정할 수 있습니다.
  • 3. Docker Desktop: WSL 2 백엔드를 사용하면 Docker 성능이 훨씬 빨라집니다.
  • 4. .wslconfig: 사용자 홈 디렉토리에 이 파일을 생성하여 메모리 및 CPU 사용량을 제한할 수 있습니다.
