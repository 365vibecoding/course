Step 1-1

풀스택 개발 환경의 이해

프로들이 윈도우에서 리눅스 환경을 고집하는 이유와 우리가 구축할 시스템의 전체 구조를 파악합니다.

🎯 우리의 목표: "배포 환경과 동일하게"

대부분의 웹 서비스는 리눅스(Linux) 서버에서 운영됩니다.

윈도우와 리눅스는 파일을 다루는 방식(예: 경로 구분자 `\` vs `/`)부터 권한 관리까지 근본적으로 다릅니다.

윈도우에서만 개발하면 "내 컴퓨터에선 되는데 서버에선 안 돼요"라는 문제가 반드시 발생합니다.

우리는 **WSL2**를 통해 이 문제를 원천 봉쇄합니다.

🏗️ 우리가 구축할 아키텍처

우리는 윈도우를 버리는 것이 아닙니다. 윈도우의 편리한 GUI 도구(VS Code, 브라우저)와 리눅스의 강력한 CLI 도구(터미널, Node, Python)를 융합합니다.

  • 3. VS Code
