Step 2-1

VS Code와 WSL 연동

윈도우에 설치된 VS Code가 리눅스 내부의 파일을 원격으로 편집하도록 설정합니다.

1️⃣ WSL 확장 프로그램 설치

VS Code 사이드바의 마켓플레이스 아이콘을 클릭하고 'WSL'을 검색하여 Microsoft가 만든 확장을 설치합니다.

2️⃣ 리눅스에서 VS Code 호출하기

이제 Ubuntu 터미널을 열고, 리눅스 파일 시스템 안에 작업 폴더를 만든 뒤 VS Code를 실행합니다.

# 홈 디렉토리로 이동

$ cd ~

# 프로젝트 폴더 생성 및 이동

$ mkdir my-awesome-project && cd my-awesome-project

# 현재 폴더에서 VS Code 열기 (점 '.' 필수!)

$ code .

3️⃣ 연동 성공 확인 (핵심!)

잠시 후 윈도우에서 VS Code가 열립니다. 창 왼쪽 하단 파란색 상태 표시줄에 아래와 같이 표시되어야 정상적으로 연결된 것입니다.

WSL: Ubuntu - 22.04

↑ 이 표시가 보이면 성공!

이제 VS Code는 윈도우에 있지만, 모든 명령과 파일 저장은 리눅스(Ubuntu) 내부에서 이루어집니다.
