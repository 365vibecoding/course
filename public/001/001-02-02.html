Step 2-2

Node.js 및 Python 설치

풀스택 개발을 위한 핵심 엔진들을 설치합니다. 모든 명령어는 Ubuntu 터미널에서 실행하세요.

🟢 1. Node.js (NVM 방식)

왜 NVM을 쓰나요? `apt install nodejs`로 설치하면 구버전이 설치되거나 권한 문제(`sudo` 필요)가 발생하기 쉽습니다. NVM은 이를 해결해 주는 버전 관리 도구입니다.

설치 명령어:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc
nvm install --lts

설치 확인 결과 (예시):

$ node -v

v20.11.1

$ npm -v

10.2.4

🐍 2. Python 및 필수 도구

Ubuntu에는 파이썬이 내장되어 있지만, 패키지 관리자(`pip`)와 가상환경 도구(`venv`), 그리고 C언어 기반 라이브러리 컴파일을 위한 빌드 도구(`build-essential`)가 필요합니다.

설치 명령어:

sudo apt update
sudo apt install -y python3-pip python3-venv build-essential

설치 확인 결과 (예시):

$ python3 --version

Python 3.10.12

$ pip3 --version

pip 22.0.2 from ...
