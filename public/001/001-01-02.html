윈도우 서브시스템(wsl)

앞으로 이 과정에서는 가능하면 Ubuntu OS를 기준으로합니다.
그래서 윈도우 환경에서는 서브시스템 즉 WSL을 설치해야 합니다.
WSL을 설치하지 않았다면 아래의 순서대로 진행해주세요.

1. WSL 활성화
1) 윈도우 터미널(또는 파워쉘)을 관리자 권한으로 열기 [참고]
2) 활성화 명령어 입력
wsl --install

3) 설치 확인 명령어 입력
wsl -list -verbose

2. Ubuntu 실행
1) 윈도우 터미널 설치
- 스토어(Microsoft Store)에서 "Windows Terminal" 설치
=> 클릭하여 설치
(혹은) 윈도우 스토어에서 "Windows Terminal" 앱 설치

2) 터미널 실행

3) 상단탭에서 우분투 선택

4) 폴더 리스트 출력 및 버전확인
ls
cat /etc/os-release
3. wsl 설치가 끝이났으면 다음 단계를 진행주세요.
