Step 3-3-샘플

Flex Lab 모범 답안

과제를 해결하기 위한 전체 코드 구조와 핵심 로직을 분석합니다.

1. 구조 및 스타일

<!-- index.html 핵심 부분 -->
<select id="select-justify">
  <option value="center">center</option>
  <option value="space-between">space-between</option>
</select>

<div id="container-row" style="display: flex; height: 200px; border: 2px solid black;">
  <!-- 아이템 5개 -->
</div>

<div id="container-col" style="display: flex; flex-direction: column; height: 400px; border: 2px solid black;">
  <!-- 아이템 5개 -->
</div>

2. 자바스크립트 로직

const selectJ = document.querySelector('#select-justify');
const selectA = document.querySelector('#select-align');
const rowCont = document.querySelector('#container-row');
const colCont = document.querySelector('#container-col');

const applyFlex = () => {
  // 사용자가 선택한 값을 가져옴
  const jValue = selectJ.value;
  const aValue = selectA.value;

  // 두 컨테이너에 동시에 적용
  [rowCont, colCont].forEach(el => {
    el.style.justifyContent = jValue;
    el.style.alignItems = aValue;
  });
};

selectJ.addEventListener('change', applyFlex);
selectA.addEventListener('change', applyFlex);

💡 왜 이렇게 작동하나요?

가장 중요한 관전 포인트는 justify-content: center를 선택했을 때입니다.

1. Row 컨테이너: 아이템들이 가로 중앙으로 모입니다.
2. Column 컨테이너: 아이템들이 세로 중앙으로 모입니다.

이는 justify-content가 항상 Main Axis(주축)를 따라 움직이기 때문입니다. 방향이 바뀌면 정렬의 '기준 축'이 바뀐다는 이 원리를 이해했다면 Flexbox 정복의 90%를 달성하신 것입니다!
