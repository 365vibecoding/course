Flex의 기본 구조: Container vs Item

🏗️ 부모와 자식의 관계

Flexbox는 두 가지 요소의 상호작용으로 이루어집니다.

1. Flex Container (부모)

display: flex;가 선언된 요소입니다. 정렬의 규칙을 정의합니다.

2. Flex Item (자식)

부모 요소 안에 포함된 자식들입니다. 부모가 정한 규칙에 따라 배치됩니다.

/* style.css */

.container {

display: flex;

}
