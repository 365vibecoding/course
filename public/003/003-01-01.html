Flex 마스터: 과정 소개 및 프로젝트 생성

현대 웹 레이아웃의 표준인 Flexbox를 배우기 위해 새로운 실습 환경을 구축합니다.

💡 왜 Flexbox를 배워야 하나요?

과거에는 요소를 배치하기 위해 float이나 table을 사용하는 복잡한 편법이 필요했습니다. Flexbox는 요소를 정렬하고 공간을 배분하는 가장 직관적이고 강력한 도구입니다.

🚀 실습 프로젝트 생성 (Vite)

# 1. flex-master 프로젝트 생성

npm create vite@latest flex-master -- --template vanilla

# 2. 폴더 이동 및 패키지 설치

cd flex-master && npm install

# 3. 프로젝트 초기화 (main.js, style.css 비우기)

code .

초기화 작업 (Cleanup)

기존 샘플 코드를 지워 순수한 도화지 상태로 만듭니다.

  • counter.js 파일을 삭제합니다.
  • main.js와 style.css의 내용을 모두 비웁니다.
  • index.html의 body 태그 안을 <div id="app"></div>만 남기고 비웁니다.
