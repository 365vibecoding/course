Step 2-1

Form 디자인: 순수 CSS 기초

프레임워크 없이 순수 CSS를 사용하여 요소를 화면 중앙에 배치하고, 입력창의 크기를 조정하는 방법을 학습합니다.

🎨 1단계: 기본 스타일 초기화 (style.css)

style.css 파일을 열고 아래 코드를 작성합니다. 전체적인 글꼴과 중앙 정렬을 설정합니다. 

/* style.css */
body {
  font-family: 'Arial', sans-serif;
  background-color: #f4f4f9;
  display: flex;
  justify-content: center; /* 가로 중앙 정렬 */
  padding-top: 100px;
  margin: 0;
}

#app {
  width: 100%;
  max-width: 500px;
  background: white;
  padding: 40px;
  border-radius: 8px;
  box-shadow: 0 4px 6px rgba(0,0,0,0.1);
  text-align: center;
}

⌨️ 2단계: 입력창 및 버튼 스타일

사용자가 가장 많이 보게 될 입력 영역의 폰트 크기를 키우고 가독성을 높입니다. 

h1 {
  font-size: 2rem;
  color: #333;
  margin-bottom: 20px;
}

#todo-input {
  width: 70%;
  padding: 12px;
  font-size: 1.1rem; /* 폰트 크기 조정 */
  border: 2px solid #ddd;
  border-radius: 4px;
}

#add-btn {
  padding: 12px 20px;
  font-size: 1.1rem;
  background-color: #0a0a23;
  color: white;
  border: none;
  border-radius: 4px;
  cursor: pointer;
}

#add-btn:hover {
  background-color: #2a2a40;
}

🔍 3단계: 결과 확인

이전 단계에서 작성한 HTML 뼈대에 스타일이 입혀진 모습입니다. 중앙 정렬과 넉넉한 폰트 크기가 적용되었는지 확인하세요.

[이미지 권장: 흰색 카드가 중앙에 배치되고 큰 글씨의 입력창이 있는 브라우저 화면]

CSS만으로도 충분히 깔끔한 웹 앱 UI를 만들 수 있습니다.

UI 디자인이 완료되었습니다. 이제 버튼을 눌렀을 때 반응하도록 로직을 구현해 볼까요?
