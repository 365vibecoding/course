Step 1-1

Vite 프로젝트 시작하기

명령어 한 줄로 현대적인 개발 환경을 구축하고, 브라우저에서 실시간으로 확인하는 방법을 배웁니다.

🛠️ 1단계: 프로젝트 생성

먼저 WSL(Ubuntu) 터미널을 열고, 프로젝트를 관리할 폴더로 이동합니다. 그 후 아래 명령어를 입력하여 Vite 프로젝트 뼈대를 생성합니다.

# todo-app이라는 이름의 Vanilla JS 프로젝트 생성

npm create vite@latest todo-app -- --template vanilla

※ 화살표 키로 옵션을 선택할 필요 없이, 위 명령어로 한 번에 설정을 마칠 수 있습니다.

📦 2단계: 의존성(Dependencies) 설치

프로젝트 폴더 안으로 이동하여, 개발에 필요한 도구들을 설치합니다.

# 폴더 이동

cd todo-app

# 패키지 설치 (node_modules 폴더 생성)

npm install

Tip: npm install을 실행해야만 프로젝트 작동에 필요한 라이브러리들이 내 컴퓨터에 다운로드됩니다.

💻 3단계: VS Code에서 코드 열기

터미널 명령어를 통해 현재 폴더를 VS Code 에디터로 즉시 엽니다.

# 현재 위치(.)에서 VS Code 실행

code .

윈도우 창으로 VS Code가 열리며, 왼쪽 파일 탐색기에서 프로젝트 구조(index.html, main.js 등)를 확인할 수 있습니다.

🚀 4단계: 개발 서버 실행 및 브라우저 확인

이제 코드를 실행하여 브라우저에 띄울 차례입니다. VS Code의 터미널이나 Ubuntu 터미널에서 입력하세요.

# 개발용 로컬 서버 실행

npm run dev

Check your Browser!

터미널에 표시된 주소(보통 http://localhost:5173)를 브라우저 주소창에 입력하세요.
