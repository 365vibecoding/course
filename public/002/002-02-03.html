데이터 영구 저장과 프로젝트 마무리

브라우저 저장소를 활용해 데이터를 보존하는 방법을 배우고, 우리의 첫 번째 웹 앱 프로젝트를 완성합니다.

🗄️ 1단계: LocalStorage 이해하기

지금까지 만든 앱은 새로고침을 하면 공들여 적은 할 일들이 모두 사라집니다. 자바스크립트 변수는 메모리에서만 동작하기 때문입니다. 데이터를 브라우저에 "포스트잇"처럼 붙여두는 기능이 바로 LocalStorage입니다.

저장하기 (Save)

localStorage.setItem('key', 'value');

불러오기 (Load)

localStorage.getItem('key');

📝 2단계: 최종 코드 완성 (main.js)

기존 로직에 '저장'과 '불러오기' 기능을 추가한 최종 코드입니다. JSON.stringify와 JSON.parse를 사용하여 배열 데이터를 문자열로 변환해 저장합니다. 

/* 최종 main.js */
const input = document.querySelector('#todo-input');
const addBtn = document.querySelector('#add-btn');
const todoList = document.querySelector('#todo-list');

// 1. 초기 데이터 불러오기
let todos = JSON.parse(localStorage.getItem('todos')) || [];

// 2. 화면에 그리는 함수
const render = () => {
  todoList.innerHTML = '';
  todos.forEach((todo, index) => {
    const li = document.createElement('li');
    li.textContent = todo;
    todoList.appendChild(li);
  });
  localStorage.setItem('todos', JSON.stringify(todos)); // 저장
};

// 3. 할 일 추가
addBtn.addEventListener('click', () => {
  if (input.value.trim()) {
    todos.push(input.value);
    input.value = '';
    render();
  }
});

// 시작 시 렌더링
render();
