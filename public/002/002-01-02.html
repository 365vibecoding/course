Step 1-2

프로젝트 초기화 및 HTML 뼈대 잡기

Vite의 기본 샘플 코드를 삭제하여 깨끗한 상태로 만들고, 순수 HTML로 앱의 구조를 설계합니다.

🧹 1단계: 불필요한 파일 제거 (Clean Up)

Vite가 생성한 초기 파일 중 학습에 방해되는 샘플들을 삭제합니다. VS Code의 탐색기에서 다음 파일들을 처리하세요.

삭제할 파일

  • counter.js
  • javascript.svg
  • public/vite.svg

수정할 파일 (내용 전체 삭제)

  • style.css (비워두기)
  • main.js (비워두기)

[이미지 권장: 삭제 후 깔끔해진 VS Code 파일 탐색기 화면]

🏗️ 2단계: 순수 HTML 뼈대 작성

index.html 파일을 열고, <body> 태그 내부를 모두 지운 뒤 아래와 같이 작성합니다. 디자인(CSS) 요소 없이 의미론적(Semantic) 구조에만 집중합니다. 

<!-- index.html -->
<div id="app">
  <header>
    <h1>Todo App</h1>
  </header>

  <main>
    <!-- 입력 영역 -->
    <section id="input-section">
      <input type="text" id="todo-input" placeholder="할 일을 입력하세요...">
      <button id="add-btn">Add Todo</button>
    </section>

    <!-- 리스트 출력 영역 -->
    <section id="list-section">
      <ul id="todo-list">
        <!-- 자바스크립트로 항목이 추가될 위치 -->
      </ul>
    </section>
  </main>
</div>

구조 설명:

  • div#app: 전체 애플리케이션을 감싸는 컨테이너입니다.
  • input#todo-input: 사용자가 글자를 입력하는 곳입니다.
  • button#add-btn: 클릭 시 입력값을 저장할 트리거 역할을 합니다.
  • ul#todo-list: 저장된 할 일들이 목록(li) 형태로 쌓일 공간입니다.

🔍 3단계: 브라우저 결과 확인

터미널에 npm run dev가 실행 중인지 확인하고 브라우저를 보세요. 디자인이 전혀 적용되지 않은 쌩얼(?)의 HTML이 보인다면 성공입니다!
