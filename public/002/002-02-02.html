Step 2-2

이벤트 처리 및 비즈니스 로직

자바스크립트로 HTML 요소를 선택하고, 사용자의 행동(클릭)에 반응하는 기능을 구현합니다.

🎯 1단계: DOM 요소 선택 (Selectors)

자바스크립트가 HTML의 특정 요소를 제어하려면 먼저 해당 요소를 "찾아야" 합니다. 이때 CSS 선택자 규칙을 그대로 사용하는 document.querySelector()를 사용합니다. 

// ID 선택자를 이용해 HTML 요소를 변수에 할당합니다.
const input = document.querySelector('#todo-input');
const addBtn = document.querySelector('#add-btn');
const todoList = document.querySelector('#todo-list');

참고: #은 ID를 의미하며, .은 클래스를 의미합니다. 특정 ID를 가진 요소는 페이지 내에서 유일해야 하므로 ID 선택자가 가장 자주 쓰입니다.

🔔 2단계: 이벤트 처리 (Event Handling)

사용자가 버튼을 '클릭'하거나 키보드를 '입력'하는 사건을 이벤트(Event)라고 합니다. 자바스크립트는 이를 감시(Listen)하고 있다가 특정 함수를 실행합니다. 

// 'click' 이벤트가 발생하면 중괄호 { } 안의 코드를 실행하라
addBtn.addEventListener('click', () => {
    console.log('버튼이 클릭되었습니다!');
});
핵심: addEventListener는 "언제(사건), 무엇을(실행할 코드)" 할지를 결정하는 약속입니다.

🚀 3단계: 마무리 코드 통합 (main.js)

입력값을 가져와 새로운 리스트 항목(li)을 만들고 화면에 추가하는 완성된 로직입니다. main.js에 아래 코드를 작성하세요. 

/* main.js */
const input = document.querySelector('#todo-input');
const addBtn = document.querySelector('#add-btn');
const todoList = document.querySelector('#todo-list');

// 추가 버튼 클릭 시 실행
addBtn.addEventListener('click', () => {
  const value = input.value.trim(); // 앞뒤 공백 제거

  if (value !== "") {
    // 1. 새로운 li 요소 생성
    const li = document.createElement('li');
    li.textContent = value;
    
    // 2. 리스트에 추가
    todoList.appendChild(li);
    
    // 3. 입력창 비우기 및 포커스
    input.value = "";
    input.focus();
  } else {
    alert("할 일을 입력해주세요!");
  }
});

이제 브라우저에서 텍스트 입력 후 버튼을 누르면 리스트가 추가 될것입니다.
